# START BLOG 2.0 — Control Room

Панель администратора клуба START BLOG 2.0: контент-календарь первого месяца (4 недели, будние дни, 20 готовых публикаций), подкасты, игры, созвоны, готовые сообщения и ритм клуба.

Статический сайт без сборки: `index.html` (всё внутри одного файла). Отметки выполнения сохраняются в браузере (localStorage).

Публикация: GitHub Pages из ветки `main`, корень репозитория.
